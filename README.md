# Cocone（ココネ）

[![IMAGE ALT TEXT HERE](https://jphacks.com/wp-content/uploads/2026/07/IMG_5316.png)](https://www.youtube.com/watch?v=piaNsc6ilBI)

## 製品概要
ぬいぐるみを通じて人の心拍と温もりを届ける機器

### 背景(製品開発のきっかけ、課題等）
言葉（テキスト）によるコミュニケーションの限界を感じたことが開発のきっかけです。
地元を離れ一人暮らしをして心を病んでしまった友人に対して、「大丈夫？」「無理しないでね」といった優しい言葉を選ぼうとしても、「上辺だけに聞こえないか」「相手のことを全て理解したような発言はしたくない」という強い心理的葛藤（言葉選びの壁）が生じました。
どれほどメッセージを重ねても「画面越し」では伝わらないもどかしさや孤立感を解消し、言葉によるアドバイスではなく、嘘のない寄り添いを提供するための新たな非言語コミュニケーションプロダクトが必要だと考えました。

### 製品説明（具体的な製品の説明）
「Cocone（ココネ）」は、遠く離れた大切な人に、言葉を超えた『体温と鼓動』を届けるぬいぐるみ型デバイスです。
文字メッセージでは伝えきれない「側にいるよ」という存在感を、物理的なぬくもり（37℃〜45℃）と、送信者側の心拍（振動）によって伝えます。また、送信者側は、その時の気分によって、相手に送る光を選択することができます。送信者がWebアプリから自分の感情や心拍を送ると、受信者は自分の好きなタイミングで、ぬいぐるみを通して温もりや相手の存在感を直感的に受け取れます。非同期性により、ストレスなく安心して利用できる「寄り添い型インターフェース」を実現しました。

### 特長
#### 1. 特長1 体温（37℃〜45℃）と鼓動と光による非言語コミュニケーション
言葉ではなく、人間が直感的に安心感を覚える「体温」と「鼓動」と「光」を再現。文字コミュニケーションで生じる「言葉選びの葛藤」から解放された、新しい寄り添い体験を提供します。

#### 2. 特長2 時間的・物理的なコミュニケーションからの解放
「今すぐ返信しなければいけない」という時間的拘束や、「同じ場所にいなければぬくもりを感じられない」という物理的距離の制約からユーザーを解放します。
非同期メッセージでありながら、言葉を介さず「いつでも相手の体温や鼓動を感じられる」体験を提供。忙しい日常や離れた場所にいても、お互いの負担にならずに存在感と安心感を共有できます。

### 解決出来ること
* **言葉コミュニケーションの限界ともどかしさの解消**：「何をかけても傷つけそう」という言葉選びの恐怖・葛藤を解消します。
* **孤立感・孤独感の和らげ**：離れて暮らす大切な人に、「側にいる安心感」を届けます。
* **言語・時間によるストレスの軽減**：ただ抱きしめるだけで心が通じる「非同期・非言語」の優しさをもたらします。

### 今後の展望
* **メンタルケア・ケアソリューション領域への展開**
  個人間の寄り添いだけでなく、言葉でのコミュニケーションが難しい場面（小児病棟、メンタルヘルスケア施設、一人暮らしの高齢者の見守りなど）へ「非言語の安全な温もり」を届けるソリューションとしての社会実装。
* **感圧センサを用いて、鼓動のリアリティの追求**
  ぬいぐるみの内部に感圧センサ（Force Sensitive Resistor）を実装し、ユーザーがぎゅっと抱きしめる強さをリアルタイムに計測。抱く力強さに応じて「鼓動の強さ」を動的に変化させるアルゴリズムを導入します。強く抱きしめると、まるで相手の心が反応してドクドクと力強く脈打つ」という双方向のインタラクティブな触感体験を作り出し、まるで生きているかのような圧倒的なリアリティと深い安心感を提供します。

### 注力したこと（こだわり等）
* **ストーリー重視の情緒的プロダクトデザイン**：「友人へ存在感を届けたい」という情熱を原点に、受け手が「抱きしめたくなる」温もりのある世界観・デザインを徹底。
* **直感的なハードウェア制御**：ぬいぐるみを抱きしめると自然に温もりと鼓動がじんわり伝わる。
