## 製品概要
ぬいぐるみを通じて人の心拍と温もりを届ける機器

### 背景(製品開発のきっかけ、課題等）
言葉（テキスト）によるコミュニケーションの限界を感じたことが開発のきっかけです。
地元を離れ一人暮らしをして心を病んでしまった友人に対して、「大丈夫？」「無理しないでね」といった優しい言葉を選ぼうとしても、「上辺だけに聞こえないか」「相手のことを全て理解したような発言はしたくない」という強い心理的葛藤（言葉選びの壁）が生じました。
どれほどメッセージを重ねても「画面越し」では伝わらないもどかしさや孤立感を解消し、言葉によるアドバイスではなく、嘘のない寄り添いを提供するための新たな非言語コミュニケーションプロダクトが必要だと考えました。

### 製品説明（具体的な製品の説明）
「Cocone（ココネ　心×音×コネクト）」は、遠く離れた大切な人に、言葉を超えた『体温と鼓動』を届けるぬいぐるみ型デバイスです。
文字メッセージでは伝えきれない「側にいるよ」という存在感を、物理的なぬくもり（37℃〜45℃）と、送信者側の心拍（振動）によって伝えます。送信者がWebアプリから自分の感情や心拍を送ると、受信者は自分の好きなタイミングで、ぬいぐるみを通して温もりや相手の存在感を直感的に受け取れます。非同期性により、ストレスなく安心して利用できる「寄り添い型インターフェース」を実現しました。

### 解決出来ること
*・言葉コミュニケーションの限界ともどかしさの解消：「何をかけても傷つけそう」という言葉選びの恐怖・葛藤を解消します。
*・孤立感・孤独感の和らげ：離れて暮らす大切な人に、「側にいる安心感」を届けます。
*・ストレスの軽減：ただ抱きしめるだけで心が通じる「非同期・非言語」の優しさをもたらします。
